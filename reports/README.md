# reports/

All human-readable reports for this pipeline, in one place (per Casey, 2026-07-13).

- **`lead-run-<date>.html` / `-analysis.md`** — the daily run debriefs. Their *canonical*
  home remains `casey-assistant/brain/lead-gen/runs/` (INDEX.md links point there); the
  copies here are a convenience mirror. The nightly autopilot debrief (`scripts/autopilot/debrief.sh`)
  copies each new debrief here automatically.
- **`creator-supply-research-<date>.html`** — ad-hoc research reports (multi-agent
  investigations, strategy work).

Auto-sync commits/pushes this directory like the rest of the repo.
