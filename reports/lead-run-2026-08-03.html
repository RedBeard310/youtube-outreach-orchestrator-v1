FIXThe "$0 burn" figure is Anthropic-only — now it says so.

The autopilot burn ledger is structurally Anthropic-only (ceilings are ANTHROPIC_SOFT_USD/ANTHROPIC_HARD_USD; it records the headless claude -p runs). Since the 2026-08-01 zero-Anthropic migration, the whole pipeline's LLM work — scoring, host-ID, vein discovery, compose, verify — runs on OpenRouter, which this ledger never sees. So burn_today.total_usd: 0 is true but reads as "the pipeline is free," which is false and quietly undercuts the LLM Spend Guard house law (it spans all providers). Fix: the burn summary and the authoritative debrief JSON now carry an explicit scope: "anthropic" field plus a one-line note that non-Anthropic/OpenRouter spend is out of scope here. Additive only — no change to throttling or halting behavior. Typecheck clean; ran the ledger CLI + debrief-data to confirm the field lands.
